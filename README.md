# Website giới thiệu Trường THPT Phú Nhuận

Website giới thiệu trường bằng tiếng Việt, thiết kế responsive cho điện thoại, máy tính bảng và máy tính. Dự án dùng HTML, CSS và JavaScript thuần nên không cần cài Node.js hay thư viện build.

## Xem website

Sau khi bật GitHub Pages, website có thể truy cập tại:

https://quang261211.github.io/THPT-Ph-Nhu-n/

## Chạy trên máy tính

1. Tải hoặc clone repository này.
2. Mở file `index.html` bằng trình duyệt.
3. Các font và ảnh minh họa cần kết nối Internet.

## Triển khai bằng GitHub Pages

1. Mở tab **Settings** của repository.
2. Chọn **Pages** ở thanh bên.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main**, thư mục **/(root)**, rồi nhấn **Save**.
5. Chờ GitHub hoàn tất triển khai; đường dẫn website sẽ hiển thị tại trang Pages.

## Cấu trúc

- `index.html` — nội dung và các khu vực của website.
- `style.css` — giao diện, bố cục responsive và hiệu ứng.
- `script.js` — menu điện thoại, thư viện ảnh phóng to và năm tự động.

## Tùy chỉnh trước khi công bố

- Thay ảnh Unsplash minh họa bằng ảnh của trường mà bạn có quyền sử dụng.
- Xác minh và cập nhật địa chỉ, thông tin liên hệ, thông tin thành tích và hoạt động bằng dữ liệu từ nhà trường.
- Website này là bản giới thiệu không chính thức, không đại diện cho phát ngôn chính thức của nhà trường.
